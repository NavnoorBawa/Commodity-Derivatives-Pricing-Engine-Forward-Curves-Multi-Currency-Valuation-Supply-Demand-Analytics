# Commodity Derivatives Pricing Engine
### Forward Curves | Multi-Currency Valuation | Supply-Demand Analytics

Python implementation of standard models for pricing commodity forwards and futures,
built as a research and learning project.

**What It Does:**
- ✅ Prices forward contracts for crude oil, gold, copper, wheat
- ✅ Calculates fair value in USD, INR, EUR, GBP, JPY
- ✅ Models inventory effects on convenience yield
- ✅ Analyzes supply-demand shocks (OPEC cuts, weather events)
- ✅ Determines market structure (contango vs backwardation)
- ✅ Uses real-time data from Yahoo Finance
